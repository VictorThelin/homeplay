# Homeplay för Google TV / Chromecast

Nedladdning av Homeplay-appen för Google TV och Chromecast (installeras med appen Downloader).
Appen innehåller inga konton eller nycklar – man går med i en familj med inbjudningskoden från
inbjudningsmejlet.

Senaste versionen: [homeplay.apk](https://github.com/VictorThelin/homeplay/releases/latest/download/homeplay.apk)
